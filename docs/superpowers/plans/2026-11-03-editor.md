Каждый шаг — вертикальный срез: сначала красный тест внешнего поведения, затем минимальная реализация и зелёный прогон.

## 01. Запуск, регистрация и первый проект

**Blocked by:** нет.

**Что получает человек:** локально запускаемый продукт, регистрация по почте и паролю, автоматический workspace и первый проект, сохранение сессии.

- [ ] Настроены React + TypeScript + Vite и один Node.js-процесс.
- [ ] SQL-миграция создаёт учётные записи, сессии, workspace, участников и страницы.
- [ ] Тесты проверяют регистрацию, вход, закрытую регистрацию и выход.
- [ ] Форма имеет русские состояния загрузки и ошибок.

## 02. Дерево страниц

**Blocked by:** 01.

**Что получает человек:** проекты и страницы создаются, переименовываются и переносятся с сохранением порядка.

- [ ] API не отдаёт и не меняет страницы чужого workspace.
- [ ] Тесты запрещают циклы и проверяют вложенность и порядок.
- [ ] Дерево раскрывается, создаёт детей и принимает drop на/между строками.
- [ ] Повтор создания с тем же ключом не создаёт дубликат.
