# План F-004 — поиск по страницам

Статус: завершено 2026-11-05; шаги 1–3 реализованы и проверены. Финальный QA: `qa-bug-hunt/bug-report-20261105-005904-f004-search-lint-final.md`.

## Шаг 1 — найти и открыть страницу

**Результат:** на desktop человек открывает поиск из боковой панели, вводит запрос, видит совпадения по названию и сохранённому Markdown и открывает страницу в существующем редакторе. Весь путь от HTTP API до экрана работает без недавних страниц и мобильной адаптации.

- Красные HTTP-тесты: совпадение в названии и тексте, регистр, литеральные `%` и `_`, отсутствие операторов, лимит 20, ранжирование, путь и контракт без полного Markdown.
- Красные HTTP-тесты доступа: участник получает свои страницы; чужой workspace — `404`, отсутствие сессии — `401`.
- Минимальный `GET /api/search` поверх существующих `pages` и проверки участия, без миграции и внешнего индекса.
- Клиентский поисковый запрос с отменой прежнего fetch и защитой от устаревшего ответа.
- Новый экран поиска по P03, пункт в `Sidebar` и открытие выбранной страницы через существующее состояние `App`; `Editor.tsx` и файлы F-003 не меняются.
- Русские состояния загрузки, пустого результата, ошибки и повторного запроса.
- Зелёные targeted tests, typecheck и ручной вертикальный сценарий.

**Блокирует:** шаг 2. **Зависит от:** согласования SA и P03/P15.

## Шаг 2 — недавние, клавиатура и mobile

**Результат:** первый срез полностью работает по `Р-22`: пустой запрос показывает локальные недавние, поиск доступен клавиатурой и на mobile, разные workspace не смешивают состояние.

- Красные клиентские тесты: 10 уникальных недавних, порядок, разделение по человеку и workspace, игнорирование страниц вне текущего bootstrap.
- Красные клиентские тесты гонок: изменение запроса и workspace отбрасывает прежний ответ.
- Локальное хранение недавних без серверной записи и миграции; обновление при открытии через дерево, недавние и результаты.
- `Cmd/Ctrl + K`, фокус в поле, `↑/↓`, `Enter`, `Esc` и возврат фокуса; пробельный запрос не вызывает API.
- Сброс запроса и выдачи при смене workspace, переключение недавних.
- Полноэкранный mobile поиск по P15 с «Отменой», общие токены и touch-цели 44 × 44 px.
- Зелёные targeted tests, typecheck, сборка и браузерные V-01—V-05.

**Блокирует:** шаг 3. **Зависит от:** шага 1.

- Полный набор тестов, включая существующие HTTP, WebSocket, F-002 и текущие проверки F-003.
- Целенаправленные мутации: участие, условие названия/текста, экранирование шаблона, лимит, ранжирование, путь, актуальность ответа и разделение недавних; каждая мутация убита, исходник восстановлен.

- Реальные сценарии V-01—V-08, включая две учётные записи, медленные ответы, два workspace, 375/768/1024/1440 px и клавиатуру.
