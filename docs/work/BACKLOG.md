# Бэклог

Идеи, которые уже названы и не входят в то, что делаем первым. Первым в коде идёт редактор: дерево страниц, полный Markdown, перетаскивание, плавное движение, совместная правка с живыми правками другого человека.

Дата среза: 2026-11-03. Как каждая фича должна работать, по образцу Notion: [FEATURE_BEHAVIOR.md](FEATURE_BEHAVIOR.md). Это черновик поведения, открытые вопросы ниже им не закрыты.

## Открытые решения

Когда выбор сделан, строка переезжает в «Решения» или в «Позже».

| ID | Вопрос | Что уже сказано |
|----|--------|-----------------|
| О-2 | «Авторезажка» | Слово из разговора 2026-11-02. В первую поставку не входит. Смысл не зафиксирован. |
| О-7 | Список прав кроме «смотреть» и «смотреть и править» | «Ещё что-то» названо, состав не закрыт. |
| О-9 | Комментарии | Названы вместе с иконкой и фоном. В первый код и в «позже» не положены. Во входящие, как они заданы сейчас, не входят. |
| О-10 | Два человека правят одно и то же место | Живые правки решены. Сливаются ли они или побеждает последняя — не сказано. История страницы не названа. |
| О-11 | Круг «любой зарегистрированный» | Это любой аккаунт сервиса, не «все участники моего workspace». У Notion такого круга нет. Подтвердить, что имелось в виду именно это. |

## Решения

| ID | Решение | Когда |
|----|---------|--------|
| Р-1 | Первым делаем редактор, не агентов и не граф | 2026-11-02 |
| Р-2 | Регистрация создаёт человеку workspace. Workspace можно создать ещё один | 2026-11-02 |
| Р-3 | В workspace не больше пяти участников, владелец входит в это число. Шестого пригласить нельзя, пока кто-то не выйдет | 2026-11-02 |
| Р-4 | Отдельной «приватной репы» нет | 2026-11-02 |
| Р-5 | Страницей можно поделиться тремя кругами: только участники workspace; любой зарегистрированный; любой по ссылке | 2026-11-02 |
| Р-6 | На круге доступа отдельно выбирается право: только смотреть либо смотреть и править. Другие права — О-7 | 2026-11-02 |
| Р-7 | Страницу правят несколько человек одновременно, и правки другого человека видно вживую | 2026-11-02 |
| Р-8 | Поиск входит в продукт и не сводится к фильтру по заголовку. В первый код редактора не входит (П-12) | 2026-11-02 |
| Р-9 | Страница одна: у неё есть текст и дочерние страницы. Глава — заголовок внутри текста. Иконка и фон у страницы | 2026-11-02 |
| Р-10 | Входящие — лента приглашений: отправил, получил, принял. Это не адрес почты внизу панели | 2026-11-02 |
| Р-11 | Первый код — дерево страниц, полный Markdown, перетаскивание, плавные анимации, совместная правка вживую. Красивый дизайн входит в этот код, а не отдельной фазой после | 2026-11-02 |

| Р-13 | Стек — вариант А из `docs/research/2026-11-02-stack.md`: TypeScript в браузере и на сервере, React, TipTap, Yjs, Postgres, один процесс. Владелец подтвердил рекомендацию агента | 2026-11-03 |

| Р-17 | Регистрация новых учётных записей включается и выключается настройкой окружения сервера (переменная env). Когда выключена, регистрация недоступна, вход существующих участников работает | 2026-11-03 |
