# Wiki

Локальный клиент-серверный редактор страниц: workspace, проекты, вложенное дерево, Markdown, живые правки и курсоры участников.

## Запуск

Требуется Node.js 24 или новее. Внешний Postgres для локального запуска не нужен: по умолчанию используется встроенный PGlite.

```bash
npm install
npm run dev
```

Откройте `http://localhost:3000`. Можно передать другой адрес и порт:

```bash
npm run dev -- --host 127.0.0.1 --port 7100
```

Данные сохраняются в `data/pgdata`, загруженные изображения — в `data/uploads`. При первом входе создайте учётную запись на вкладке «Регистрация».

## Production

```bash
npm run build
npm start
```

Один процесс отдаёт собранный React-интерфейс, REST API и WebSocket `/collaboration`.

## Настройки

- `DATABASE_URL` — строка подключения к внешнему Postgres вместо PGlite.
- `WIKI_DATA_DIR` — каталог встроенной базы, по умолчанию `./data/pgdata`.
- `WIKI_UPLOAD_DIR` — каталог изображений, по умолчанию `./data/uploads`.
- `REGISTRATION_ENABLED=false` — закрыть регистрацию, не закрывая вход существующих пользователей.
- `HOST`, `PORT` — адрес и порт HTTP-сервера.
- `LOG_LEVEL` — уровень серверных логов, например `info` или `fatal`.

## Проверки

```bash
npm test
npm run build
node scripts/mutation-check-search.mjs
```

Тесты покрывают регистрацию и вход, CSRF при выходе, идемпотентное создание, обновление и перенос страниц, запрет циклов и чужого доступа, синхронизацию Yjs, awareness и сохранение Markdown. Для поиска проверяются HTTP-контракт и доступ, сортировка и лимит выдачи, недавние страницы, гонки запросов, нагрузка на 1000 страниц и браузерные сценарии desktop/mobile.

## Что входит в текущую поставку

- Регистрация, вход по почте и паролю, серверные сессии.
- Несколько workspace; проекты как корневые страницы.
- Создание, переименование и перетаскивание страниц.
- TipTap: Markdown-ввод, форматирование, списки, задачи, таблицы, код, ссылки и изображения.
- Меню `/`, операции с одиночными и групповыми блоками, перетаскивание, оглавление, экспорт `.md`.
- Yjs + Hocuspocus: живой текст, курсоры и присутствие.
- Поиск по названию и Markdown текущего workspace, `Cmd/Ctrl + K`, клавиатурная навигация и недавние страницы.
- Адаптивная панель страниц, редактор и полноэкранный мобильный поиск.

Приглашения, круги доступа, входящие, агенты, граф и плагины в эту поставку не входят. Статическая публикация невозможна: продукту нужны API, сессии, Postgres и WebSocket.
